# showcase app that simulates cars and trafficlights at intersection
## Running the app
go to root directory and type:
### python graphics.py
or in flask branch:
### python app.py

Runs the app in the development mode at [http://localhost:3005](http://localhost:3005)


or

use the precompiled binary for windows:

intersectionbinaries/windowsbin/graphics.exe

binary for linux:

intersectionbinaries/linuxbin/graphics

Also (flask branch) works as backend for [https://github.com/tjuho/intersection-frontend](https://github.com/tjuho/intersection-frontend).

Running demo can be found in my Homepage [https://omatestiserveri.mooo.com/](https://omatestiserveri.mooo.com/).
